{% tr 'Горячие клавиши' %}

Отключаются в настройках. Работают при русской раскладке (используется физическая клавиша). При вводе текста срабатывают только сочетания с Alt.

{% tr 'Брендбук' %}

Глобальные

  • Alt+KКомандная строка / поиск
  • Alt+OСписок заказов
  • Alt+NНовый товар
  • Alt+EРедактировать выбранный товар
  • Alt+GНа обзор
  • Alt+TПереключить тему
  • Alt+/Фокус в поиск списка
  • Alt+HЭта справка

Контекстные (одиночные буквы)

Срабатывают, когда фокус не в поле ввода. Работают в любой раскладке.

  • /Фокус в поиск списка
  • ?Эта справка
  • GНа обзор
  • SСменить статус (в карточке заказа)
  • IПриход товара
  • WСборка и списание
  • PПечать накладной PDF

Резервный путь

  • \ затем KКомандная строка
  • \ затем OЗаказы
  • \ затем NНовый товар
  • \ затем EРедактировать
  • \ затем GНа обзор
  • \ затем SСменить статус
  • \ затем IПриход
  • \ затем WСборка
  • \ затем PПечать
