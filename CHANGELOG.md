# Журнал изменений

## [1.0.0] — 2026-10-19

### Добавлено
- Публичная витрина: каталог с деревом категорий, серверными фильтрами (бренд, цена, наличие, характеристики), динамическими фасетами, сортировками и пагинацией по 50; полнотекстовый поиск PostgreSQL с морфологией; карточка товара с каруселью, характеристиками, отзывами, вопросами и рекомендациями; избранное.
- Корзина с серверной проверкой остатка и резервом на 20 минут, промокоды, перенос гостевой корзины при входе.
- Атомарное оформление заказа (заказ + резерв + платёж + уведомление), имитация ЮKassa с подписанным веб-хуком, оплата при получении, отмена покупателем с возвратом денег.
- Личный кабинет: профиль, история и карточка заказа со статусами, отзывы, возвраты, избранное.
- Склад: приход со сверкой, журнал движений, резервы, сборка с отметкой позиций, списание, обратная операция при отмене, накладные и ярлыки PDF.
- Платежи: лог запросов/ответов шлюза, ручное подтверждение, частичные/полные возвраты с учётом комиссии, импорт выписок CSV/XLSX и автосверка.
- Возвраты с регламентом статусов, блокировкой после одобрения и версионированной аудиторской правкой.
- Отзывы: проверка покупки, премодерация, ответы продавца, атомарный пересчёт рейтинга.
- Панель: справочники (характеристики, единицы, причины возврата), акции с условиями и привязкой к товарам/категориям/брендам, массовые операции, сохранённые и дефолтные фильтры, многостолбцовая сортировка, журнал изменений в карточках, связанные объекты.
- Отчёты (5) с графиками Chart.js и экспортом CSV/PNG.
- Импорт товаров, остатков, цен (предпросмотр, сопоставление колонок, всё-или-ничего); экспорт каталога CSV/YML, заказов CSV.
- Контур администратора БД: характеристики СУБД, таблицы, индексы, роли и гранты, миграции, pg_stat_statements, бэкапы/проверка restore/восстановление, регламентные задания с планировщиком, сервисные учётки (API-токены), архивация и временный доступ к архиву; обязательный аудит и HTTPS.
- REST API v1 (маркетплейсы, мобильное приложение, callback ЮKassa, внутреннее) со спецификацией OpenAPI.
- Пользовательские настройки на сервере (тема, язык RU/EN, форматы, размер страниц, дефолтные фильтры), 12 горячих клавиш, командная строка Alt+K, брендбук.
- 91 автотест; команды `generate_products`, `benchmark_catalog`, `load_test`; скрипты бэкапа/restore для Linux и Windows.

### Изменено
- Пароли хешируются Argon2 (старые PBKDF2-хеши перехешируются при входе).
- Матрица RBAC расширена; отказ в доступе возвращает 403 и пишется в аудит.
- Списание при сборке учитывает собственный резерв заказа (ранее сравнивалось со свободным остатком).

## [0.1.0]
- Базовая модель данных, панель управления, RBAC, статусы заказов, склад, аудит.
